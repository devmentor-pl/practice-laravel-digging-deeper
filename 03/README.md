# `#03` Laravel: Digging deeper (19-22)

Dodaj opcję wysyłania wiadomości email w momencie tworzenia nowego wpisu - wystarczy, że użytkownik zaznaczy w formularzu opcję "wyślij na mój adres email".

Wykorzystaj do tego [powiadomienia (notifications)](https://laravel.com/docs/12.x/notifications). Wiadomość powinna być wysyłana w tle przy pomocy kolejki, aby użytkownik nie musiał czekać na jej wysłanie.

Do podglądu wiadomości lokalnie możesz użyć np. [Mailpit](https://mailpit.axllent.org/).
